# Backend Developer Intern

## About the Role

We are looking for a Backend Developer Intern to help build
scalable backend applications and REST APIs. The intern will
work with the development team to design, implement, test,
and maintain backend services.

## Requirements

### Technical Skills

- Java
- Spring Boot
- REST APIs
- SQL
- MySQL
- Git
- Basic Docker knowledge

### Experience

- Experience building backend projects
- Experience developing REST APIs
- Academic or internship experience in backend development is preferred

### Education

- Currently pursuing a degree in Computer Science,
  Information Technology, or a related field

### Certifications

- Relevant backend, Java, cloud, or database certifications
  are preferred

### Domain Knowledge

- Understanding of backend development
- Understanding of databases
- Understanding of API development
- Basic understanding of software development practices

### Soft Skills

- Problem solving
- Communication
- Teamwork
- Ability to learn quickly
- Adaptability

## Responsibilities

- Develop and maintain REST APIs
- Work with Java and Spring Boot
- Perform database operations using SQL/MySQL
- Debug and test backend applications
- Collaborate with team members
- Follow Git-based development workflows
- Learn and apply new backend technologies

## Nice to Have

- Docker experience
- Cloud platform knowledge
- Knowledge of authentication and authorization
- Understanding of basic system design
